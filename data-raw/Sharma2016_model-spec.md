## Scope / domain of applicability

- **Jurisdiction / region:** Ontario (FESC + OMNR permanent sample plots,
  400 m², mostly one measurement). Jack pine/black spruce/white spruce plots
  cover the boreal region; red pine plots are mostly in the southwest of
  the province (p.71).
- **Species covered (NFI codes):** PINU.BAN, PINU.RES, PICE.MAR, PICE.GLA.
- **Stand origin:** plantation (regenerated by planting; mostly pure) vs
  natural stand (mostly mixed) (p.71). Separate parameters per origin.
- **Valid input ranges:** per species × origin, Tables 1–2 p.72 → CSV
  `*_min/*_max`. DBH min 2.5 cm everywhere.
- **Caveats from the source:**
  - Dead, defective-at-DBH, and broken-top trees excluded (p.71).
  - Population ("fixed response") prediction = Eq. 4 "without the random
    parameter" (Fig. 4 caption, p.76).

## Variables and units

| Symbol | Meaning | Units |
|--------|---------|-------|
| h_ij | total height of tree j in plot i | m |
| D_ij | diameter at breast height | cm |
| SHT | dominant stand height | m |
| BA | stand basal area | m²/ha |
| TPH | stand density | trees/ha |
| θ, δ, β, φ, γ | fixed parameters (Table 3) | – |
| u_i | random plot effect on θ, u_i ~ N(0, τ) | – |
| σ²_e, σ²_u | residual and random-effect variances (Table 3) | – |

## Model form(s)

```
Eq. 1, p.72 (fixed form, from Sharma & Parton 2007):
  H = 1.3 + α · SHT^δ · (1 − exp(−β · (TPH/BA)^φ · D))^γ

Eq. 4, p.75 (mixed form):
  h_ij = 1.3 + (θ + u_i) · SHT_i^δ · (1 − exp(−β · (TPH_j/BA_j)^φ · D_ij))^γ + e_ij
  u_i ~ N(0, τ)

Population prediction (v1): u_i = 0
  H = 1.3 + θ · SHT^δ · (1 − exp(−β · (TPH/BA)^φ · D))^γ
```

- Identical to `hd_sharmaparton2007` (α ≡ θ) → reuse `.hd_cr_stand()`
  from `R/hd_utils.R`.
- **Negative exponents (verified on render; text p.75 confirms):** φ < 0 for
  red pine natural; δ < 0 and φ < 0 for black spruce natural. So for SB
  natural, height *decreases* slightly with SHT, and for PR/SB natural it
  decreases with TPH/BA. These are as published, not errors.
- H → 1.3 as D → 0 (γ > 0 for all rows).
- **Direction(s):** height from DBH + HDOM + BA + TPH only.

## DBH–height (hd) models only

- **Height convention:** total height; 1.3 m additive offset.
- **Fit type:** SAS NLMIXED (v9.4), one fit per species × origin (p.75).
  Heteroscedasticity checked; none found (p.75).
- **Coefficients for population prediction:** Table 3 fixed effects with
  u_i = 0 (only fit published; the source uses this for Fig. 4).
- **Random-effects structure:** single random effect u_i on θ; grouping =
  plot (p.75).
- **Variance components transcribed:** Table 3 → CSV `sigma2_e`,
  `sigma2_u`. Not used in v1. AIC → `aic`. SEs not transcribed.
- **Back-transformation:** none.
- **Variants:** `variant = "natural" | "plantation"` (explicit argument;
  disjoint parameter sets). Proposed default: none (user must choose), or
  `"natural"`? ⚠D.
- **Source species mappings:** none.

- **Fidelity (Tier 1):** none. No worked example or prediction table.
- **⚠C Fig. 4 (p.76) does not reproduce exactly from Table 3.** Inputs are

  a 200-dpi render (`tmp/sharma2016/fig4-7.png`, ≈ ±0.15 m):

  | PJ natural | ≈13.2 | 12.97 | ≈17.9 | 18.20 |
  | PR plantation | ≈13.4 | 13.38 | ≈17.9 | 17.89 |

  | SB plantation | ≈10.7 | 10.59 | ≈17.9 | 16.63 |

  - Agreement is good at small to mid DBH. At D = 40, the gaps are up to 1.2 m.
  - SB and WS plantation curves in the figure exceed the Table 3 asymptote
    1.3 + θ·16^δ (16.99 and 19.48 m). **No φ value and no transcription
    fix can explain this**, so the figure was likely drawn from different
    estimates or inputs.
  - Text crossover DBH values (p.76: PJ ≈18, PR 32, SB 16, WS ≈25 cm) also
    differ from those computed from Table 3 (20.3, 28.9, 13.5, 22.2 cm).
  - Proposal: implement **Table 3 as published**. Use Fig. 4 only as a
    qualitative check:
    - plantation taller than natural at small DBH for every species;
    - curves cross once, with natural taller at D = 40;
    - Table 3 values within 0.3 m of the figure at D = 10.
  - Do not assert agreement at D = 40. Document the inconsistency in the
    roxygen `@details` and NEWS.
- **Plausibility (Tier 2):**
  - Monotone increasing in DBH (γ > 0, β > 0 all rows); H(0) = 1.3.
  - HDOM direction: ↑ for all rows except SB natural (δ < 0, very weak).
- **Cross-model:** `hd_sharmaparton2007` (Ontario, same form) for the 4
  species at BA 25, TPH 2200, HDOM 16, DBH 5–35. Report the differences
  per origin; do not assert agreement.
