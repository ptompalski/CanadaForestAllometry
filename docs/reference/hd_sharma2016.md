# Sharma (2016) DBH–height models for Ontario plantations and natural stands

Vectorized implementation of the population-level individual-tree
height–diameter models of Sharma (2016), fitted separately to trees
grown in plantations and in natural stands in Ontario. Predicts total
tree height (m) from DBH (cm), stand origin and three stand-level
predictors: dominant stand height, basal area and stand density.

## Usage

``` r
hd_sharma2016(DBH, species, variant, HDOM, BA, TPH, keep_model_id = FALSE)
```

## Arguments

- DBH:

  Numeric vector. Tree level. Diameter at breast height (1.3 m above
  ground), in cm. Must be `>= 0`.

- species:

  Character vector. Tree level. NFI species codes (e.g. `"PICE.MAR"`;
  compact `"PICEMAR"` is accepted).

- variant:

  Character vector. Plot level. Stand origin selecting the parameter
  set: `"plantation"` (regenerated by planting) or `"natural"` (natural
  stand). No default; recycled like the other inputs, so stands of both
  origins can be predicted in one call. `NA` gives `NA` height.

- HDOM:

  Numeric vector. Plot level. Dominant stand height (m): "average height
  of dominant and codominant trees" in the plot (source "SHT", pp.
  71-72). Must be `> 0`.

- BA:

  Numeric vector. Plot level. Total stand basal area (m²/ha) of the plot
  (source "BA", pp. 71-72). The source does not state a minimum DBH for
  this total. Must be `> 0`.

- TPH:

  Numeric vector. Plot level. Stand density (stems/ha), "calculated from
  the trees with dbh \\\geq\\ 2.5 cm" (source "TPH", p. 71). Must be
  `> 0`.

- keep_model_id:

  Logical. If `TRUE`, add column `model_id` (`"sharma2016_natural"` or
  `"sharma2016_plantation"`).

## Value

A tibble with column `height` (m) and, if `keep_model_id = TRUE`,
`model_id`.

## Details

**Model scope (species coverage):** jack pine (`PINU.BAN`), red pine
(`PINU.RES`), black spruce (`PICE.MAR`) and white spruce (`PICE.GLA`),
each with a plantation and a natural-stand parameter set. Fitted to
Ontario permanent sample plots (400 m²); red pine plots are mostly in
the southwest of the province, the other species cover the boreal region
(p. 71).

**Model form** (eq. 4, p. 75; same form as Sharma and Parton 2007, see
[`hd_sharmaparton2007()`](https://ptompalski.github.io/CanadaForestAllometry/reference/hd_sharmaparton2007.md)):
\$\$H = 1.3 + \theta \\ HDOM^{\delta} \[1 - \exp(-\beta (TPH /
BA)^{\phi} DBH)\]^{\gamma}.\$\$

**Height convention:** total tree height; DBH measured at 1.3 m, so
predicted height tends to 1.3 m as DBH tends to 0.

**Population-level prediction:** coefficients are the fixed effects of
the mixed-effects fit (Table 3, p. 74), evaluated with the plot-level
random effect on \\\theta\\ set to zero (\\u = 0\\), as in Fig. 4 of the
source. Plot-specific calibration with measured heights is not
implemented.

**Notes on the published coefficients:**

- As published, \\\phi\\ is negative for red pine in natural stands, and
  \\\delta\\ and \\\phi\\ are negative for black spruce in natural
  stands (p. 75). For these, predicted height decreases slightly with
  `TPH / BA` (and, for natural black spruce, with `HDOM`).

- \\\phi\\ for white spruce plantations is blank in Table 3 (the only
  non-significant parameter, p. 75). It is set to 0 here, so the
  `TPH / BA` term drops out and `BA` and `TPH` do not affect that model.

- Table 3 does not exactly reproduce the curves in Fig. 4 at large DBH
  (differences up to about 1.2 m at 40 cm); this function implements
  Table 3 as published.

Rows with `NA` in any input return `NA` height. Inputs outside the range
of the fitting data for the species and stand origin (DBH, Table 2; BA,
TPH and HDOM, Table 1; p. 72) are computed and reported in a single
warning.

## Examples

``` r
hd_sharma2016(
  DBH = c(10, 20, 30),
  species = "PINU.RES",
  variant = c("plantation", "natural", "natural"),
  HDOM = 16, BA = 25, TPH = 2200
)
#> # A tibble: 3 × 1
#>   height
#>    <dbl>
#> 1   13.4
#> 2   15.0
#> 3   17.9

# Inside dplyr::mutate() with tree and plot data
trees <- data.frame(
  DBH = c(12, 25, 18),
  species = c("PICE.MAR", "PICE.GLA", "PINU.BAN"),
  origin = c("plantation", "natural", "natural"),
  HDOM = c(12, 18, 18), BA = c(22, 30, 30), TPH = c(3000, 2000, 2000)
)
dplyr::mutate(trees, hd_sharma2016(DBH, species, origin, HDOM, BA, TPH))
#>   DBH  species     origin HDOM BA  TPH   height
#> 1  12 PICE.MAR plantation   12 22 3000 10.09483
#> 2  25 PICE.GLA    natural   18 30 2000 17.43386
#> 3  18 PINU.BAN    natural   18 30 2000 17.65263
```
